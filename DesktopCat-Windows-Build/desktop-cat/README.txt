デスクトップペット v0.4.5

まず試す場合:
ZIPをすべて展開し、BUILD_EXE.batを実行してください。
dist\DesktopCat-Dev-v0.4.5.exeを開くと、更新URLなしでGUIが起動します。
GUIから茶トラねこ、柴犬、スズメを選んで表示できます。

ネコと犬は画面下部を左右に歩き、時々2〜4分眠ります。
スズメは小さく3回ジャンプ→2秒停止を繰り返し、ときどき羽ばたきます。
スズメが眠ると目を閉じて静止し、zzzを表示します。
ごはんで起きてハートが出ます。「眠る / 起きる」で手動確認もできます。
GUIの×で全体を終了。最小化は表示を維持します。

全コンテンツ無料、寄付は任意。寄付先未設定ではDonateボタンは準備中です。
開発版の設定は一般配布版とは別に保存します。
開発版では更新確認・追加キャラのオンライン一覧を使わず、内蔵3種類を試せます。

一般配布の手順はBUILD.txtとpublisher/README.txtを参照してください。
BUILD_RELEASE.batで作成する版は公開更新URLの設定が必須です。
Windows実行ファイルのビルド・実機での動作確認は未実施です。
